# Build "Assignment Radar" — Student Assignment Management Website

Create a polished, modern, fully functional student web application called **Assignment Radar**.

## 1. Core Problem

College students often miss assignments because deadlines, instructions, and submission links are scattered across WhatsApp groups, Google Classroom, PDFs, and messages.

**Assignment Radar** solves this by putting all assignments into one simple dashboard and intelligently showing students what needs attention first.

This should feel like a real product, **not a basic to-do list**.

---

# 2. Tech Requirements

Build this as a complete frontend web application that can run locally in VS Code.

Use:

* HTML
* CSS
* JavaScript

You may use a lightweight frontend library only if genuinely necessary, but keep the project simple and reliable.

Do NOT require:

* Paid APIs
* Claude API
* OpenAI API
* Authentication services
* External databases
* Complex backend setup

Use **localStorage** to save assignments so the data remains after refreshing the page.

The website must work immediately after opening/running the project.

---

# 3. Design Direction

Create a **premium, modern student dashboard**.

Style:

* Clean
* Spacious

* Slightly futuristic
* Soft rounded cards

* Excellent typography

# 5. Workload Radar ⭐

This is one of the main unique features.

Create a weekly workload visualization.

Example:

MON  ██
TUE  ████
WED  ███████
THU  ██
FRI  █████

The workload should be calculated from assignments due on each day.

Use estimated effort to make the workload more meaningful.

For example:

* 30 minutes → small workload
* 1 hour → medium workload
* 2+ hours → large workload

Clearly highlight overloaded days with:

**⚠️ Heavy workload**

This should help students understand WHICH DAY is going to be stressful instead of simply showing how many assignments they have.

---

# 6. Smart Priority ⭐

Do not rely only on manually selected priority.

Calculate a recommended priority using:

**Deadline + Estimated Effort + Importance**

For example:

Physics Assignment
Due tomorrow
Estimated effort: 2 hours
Importance: High

→ 🔴 HIGH PRIORITY

Math Assignment
Due in 5 days
Estimated effort: 1 hour

→ 🟡 MEDIUM PRIORITY

English Assignment
Due in 10 days
Estimated effort: 30 minutes

→ 🟢 LOW PRIORITY

Show a small label such as:

**Smart Priority: HIGH**

The calculation does not need to be AI-powered. Use a clear JavaScript scoring system.

# 16. Data Handling

Use localStorage.

Every time an assignment is:

* Added
* Edited
* Deleted
* Marked submitted

the localStorage data must update.

Refreshing the browser must NOT delete assignments.

Handle invalid or missing data safely so the website does not crash.
